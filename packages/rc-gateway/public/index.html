Rename session
Gives a session a title of your own, replacing the one in the list beside it. Enter the session id (blank means the session you're watching), type a title and tap Set title. Two limits are worth knowing before you do. This reaches a session the daemon has open: a transcript it is not currently running answers that there is nothing to rename, and the title on disk is left alone. And the durable record is written after the reply, so the list can still show the old title for a moment; the name printed here is the one the daemon says it holds. 200 characters is the limit, and a title over it is refused rather than cut short. Needs session-write scope.
(titles a session the daemon has open; requires session-write scope)

Prompt queue

Dropping a waiting prompt takes it out of the queue; dropping the one in flight cancels that turn. Needs session-read scope.

Mid-turn messages
Messages the daemon took while a turn was already running, which it holds to deliver into that turn instead of starting a new one. This is what the daemon is holding right now, not what this browser has not sent. Enter the session id (blank means the session you're watching) and tap List messages. Type a message and tap Send into turn to hand it to the turn already running; the daemon holds it until its next tool boundary. Once held, a message is never sent twice, so withdraw is the only way to take one back. Deliver now asks the daemon to stop holding what it has and push it in before that boundary, which cuts a streaming response short; it does nothing when nothing is waiting. Listing needs session-read scope, sending needs session-write.
(messages held during a running turn; list with session-read, send with session-write)

Search
Full-text search across every recorded session transcript. Type a query (AND works, e.g. oauth refresh AND error), optionally narrow by message kind or date range, then tap Search. rank (BM25) orders results by relevance; it needs the index built with qwen-rc reindex and otherwise falls back to a slower scan. all daemons also searches the other daemons. Shortcut: ⌘K / Ctrl-K from anywhere. Needs owner scope.
(transcripts; requires owner scope) — ⌘K / Ctrl-K

Permission rules
The allow / ask / deny lists that decide what the agent may do. allow runs without a prompt, ask always prompts you, and deny is blocked. Pick a scope (workspace = this project, user = all your projects), type a rule such as shell(git status:*) or edit(./docs/**), tap add, then save that list — nothing is applied until you save. Needs an owner token and a trusted workspace. If saving says a session is required, send a prompt in that workspace and retry.
Permission decisionsgateway-visible decisions only
A read-only log of recent permission decisions the gateway saw: which rule fired for a tool call, and the votes you made on permission prompts. Filter by tool or rule id and tap query to check that a rule you set behaves the way you intended. Decisions the daemon makes locally never reach the gateway, so they don't appear here.
Session overridesephemeral — lost when the gateway restarts
Temporary permission rules that expire on their own. Choose a session (blank = all sessions), a tool, an action (allow / deny / prompt) and how long it lasts, then tap set. Tap revoke on a row to remove one early. Overrides live only in the gateway's memory, so restarting the gateway clears them.

Stream
Controls the live event connection to the session shown in the status bar and transcript on the Chat tab. Watch (re)attaches and replays from the start; Unwatch stops following and cancels the automatic reconnect retries — the turn keeps running on the host either way. Self-heal normally reattaches on its own after a drop; use this only if it gives up or you want to deliberately detach.
(the watched session's event feed; the status bar above shows its live state)
